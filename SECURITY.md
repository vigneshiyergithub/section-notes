# Security

Do not put credentials, session tokens, private screenshots, or full sensitive URLs
in a public issue. Use synthetic pages and redact reproduction material.

For vulnerabilities, prefer GitHub's private vulnerability reporting on this
repository when enabled. If it is unavailable, ask the maintainer for a private
reporting channel without including exploit details or private data in the request.

The extension stores screenshots and comments locally, without extension-managed
encryption. ZIP files include visible page content and source URLs. Reset retains
a recovery snapshot and is not secure erasure. There is no remote upload or
redaction service. See README.md for the exact permissions and limitations.
